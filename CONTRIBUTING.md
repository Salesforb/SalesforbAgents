# Contribuire a SalesForB Agents

1. Crea un branch con prefisso `codex/` o `feature/`.
2. Mantieni le credenziali esclusivamente nell’installazione locale.
3. Verifica la dashboard alle larghezze desktop e mobile.
4. Controlla che la console del browser non presenti errori.
5. Descrivi nella pull request le modifiche visive e funzionali.

Non inserire mai nella repository file `.env`, token OAuth, database, profili Chrome, email, dati cliente o backup locali.
